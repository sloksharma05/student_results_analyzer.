# Student Result Analyzer 

A beginner-friendly Python project to manage and analyze student marks using CSV, pandas, and matplotlib..

##  Features

- Add student records
- View all data
- Analyze average, topper, lowest scorer
- Plot subject-wise marks bar chart
- Search student by Roll No

##  Tech Stack

- Python
- pandas
- matplotlib
- CSV file for storage



##  How to Run

```bash
pip install pandas matplotlib
python result_analyzer.py
```
